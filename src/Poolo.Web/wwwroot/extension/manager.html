دارایی و اقساط ثبت‌شده از پنج سرویس

ورود دستی جدول؛ اطلاعات فقط در این صفحه می‌ماند. برای نگهداری، خروجی JSON بگیر و در «دمِ دست» وارد کن.

اتصال به دمِ دست

چطور استفاده کنم؟
  1. در سایت رسمی هر سرویس، وارد حساب خودت شو و صفحه دارایی یا اقساط را باز کن.
  2. روی افزونه بزن و «خواندن همین صفحه» را انتخاب کن.
  3. ستون‌ها، واحد مبلغ، حساب و ردیف‌ها را بررسی و ذخیره کن.
  4. برای صفحه‌های بعدی تکرار کن؛ اطلاعات جدید با ردیف‌های قبلی ادغام می‌شود.
  5. در PWA، بخش «تجمیع» را باز کن و «دریافت از افزونه» را بزن.

اسکن خودکارِ تمام صفحات و اتصال API خصوصی انجام نمی‌شود. جدول‌های واقعی هر سرویس هنوز با حساب کاربری آزمایش نشده‌اند. اگر جدولی پیدا نشد، داده کپی‌شده یا CSV را وارد کن. ورود و رمزها در خود سرویس می‌مانند.

بررسی اطلاعات

پیش‌فرض: فهرست ناقص. ردیف‌های قبلی حفظ می‌شوند. برای دو وام هم‌نام با سررسید یکسان، ستون شناسه یکتا را انتخاب کن.
