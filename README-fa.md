# دمِ دست · DameDast

نام پروژه‌ها و namespaceها DameDast است. گزینه‌های داخل دسته‌بندی منو بدون محدودیت تعداد پین می‌شوند. تراکنش‌ها به‌شکل ردیف‌های فشرده در سه ستون دسکتاپ، دو ستون تبلت و یک ستون گوشی نمایش داده می‌شوند. گروه‌های تنظیمات در ابتدا بسته‌اند و کارت‌های مالی گوشی کوتاه‌تر شده‌اند. یادداشت‌ها چیدمان با ارتفاع متناسب با محتوا، نمای شبکه‌ای/لیستی، بخش پین‌شده و دسترسی سریع به ایجاد یادداشت و چک‌لیست دارند؛ نقاشی و PDF حفظ شده‌اند. پنهان‌سازی مبالغ از ستاره استفاده می‌کند. تقویم تعطیلات تا ۱۴۱۰ داخل برنامه است؛ تاریخ مناسبت‌های قمری آینده برآوردی است.

در ارتقا، داده‌های مرورگر قدیمی خودکار منتقل می‌شوند؛ اطلاعات جدید جایگزین نمی‌شوند. دیتابیس سرور قدیمی در شروع به `damedast.db` کپی می‌شود و فایل اصلی باقی می‌ماند. به علت تغییر هویت برنامه ممکن است ورود دوباره لازم باشد. برای Docker، اگر نام پروژهٔ Compose قبلی متفاوت است، متغیر `DAMEDAST_DATA_VOLUME` را به نام volume فعلی تنظیم کن.

> به‌روزرسانی رابط: مبلغ‌های داشبورد ابتدا پنهان‌اند؛ دکمهٔ چشم، فرم تودوی ساده با «بیشتر»، تاریخ‌های مرتب، ظاهر مات و حذف گزینهٔ Libraries اضافه شده‌اند.

> این مخزن شامل سورس کامل بک‌اند ASP.NET Core 10، رابط وب و PWA، سورس React/TypeScript بوم، افزونه، تست‌ها و فایل‌های استقرار است.
>
> آخرین تغییرات: تنظیمات میز کار و تقویم، منوی شعاعی آیکونی +، نمایش PDF در یادداشت‌ها و بکاپ جداگانهٔ یادداشت‌ها و اطلاعات مالی. فایل‌های PDF در مرورگر نگه‌داری می‌شوند و با بکاپ یادداشت‌ها منتقل می‌شوند؛ همگام‌سازی بایت‌های PDF با سرور پیاده‌سازی نشده است.
>
> اجرای محلی: `dotnet run --project src/DameDast.Web --urls http://localhost:5000 --environment Development` (نیازمند SDK دات‌نت ۱۰).

# دمِ دست

دمِ دست با بک‌اند ASP.NET Core 10، معماری کلین و رابط دو زبانهٔ فارسی و انگلیسی ساخته شده است. یک بار روی سرور منتشر می‌شود و همان آدرس هم وب است و هم به‌صورت PWA روی گوشی نصب می‌شود. این پروژه APK یا .NET MAUI نیست.

## اجرای سریع

پس از نصب SDK دات‌نت ۱۰، از پوشهٔ پروژه اجرا کن:

```bash
dotnet run --project src/DameDast.Web --urls http://localhost:5000 --environment Development
```

آدرس `http://localhost:5000` را باز کن. **Explore the demo** فضای نمونهٔ جدا از داده‌های واقعی است. بخش‌های Overview، Transactions، Accounts، Budgets، Savings goals، Reports و Settings آماده‌اند.

مبلغ‌ها تومان و عدد صحیح‌اند. تاریخ‌ها، انتخاب روز و ماه، گزارش‌ها و برنامه‌های ماهانه در هر دو زبان شمسی‌اند. تاریخ در ذخیره‌سازی ISO است و بودجه‌های قدیمی بازهٔ اصلی خود را حفظ می‌کنند. انتقال بین حساب‌ها درآمد یا هزینه نیست؛ مبلغ هدف پس‌انداز هم صرفاً برای پیگیری است و خودش موجودی حساب را تغییر نمی‌دهد.

## اتصال گوگل

در Google Cloud Console یک OAuth Client از نوع Web application بساز. آدرس بازگشت را `https://YOUR-DOMAIN/signin-google` قرار بده. برای تست محلی هم `http://localhost:5000/signin-google` را اضافه کن. سپس Client ID و Client Secret را با user-secrets یا متغیرهای محیطی روی سرور تنظیم کن. دستورهای دقیق در README.md هستند.

گوگل فقط هویت کاربر را مشخص می‌کند؛ دادهٔ مالی روی سرور خود برنامه ذخیره می‌شود. برای همگام‌سازی، همهٔ دستگاه‌ها باید به همان دامنه و همان حساب گوگل وصل شوند. بدون کلیدهای گوگل، حالت محلی قابل استفاده است و ورود و سینک واقعی فعال نیست.

## انتشار روی سرور

فایل `.env.example` را با نام `.env` کپی کن و DOMAIN، GOOGLE_CLIENT_ID و GOOGLE_CLIENT_SECRET را پر کن. دامنه باید به سرور اشاره کند و پورت‌های ۸۰ و ۴۴۳ باز باشند.

```bash
docker compose up -d --build
```

Caddy گواهی HTTPS را دریافت می‌کند و درخواست‌ها را به برنامه می‌فرستد. دیتابیس و کلیدهای نشست در volume باقی می‌مانند. برای نصب در Chrome اندروید گزینهٔ Install app یا Add to Home screen را بزن.

## کار آفلاین و تعارض

تغییرات ابتدا در IndexedDB ذخیره می‌شوند. با اتصال مجدد، وقتی برنامه باز باشد، به سرور ارسال می‌شوند. اگر یک رکورد روی دو دستگاه ویرایش شده باشد، برنامه انتخاب نسخه را به تو می‌سپارد. درخواست تکراری دوباره اثر مالی نمی‌گذارد.

داده‌های مهمان خودکار وارد حساب گوگل نمی‌شوند؛ از Settings گزینهٔ **Bring your local data along** را انتخاب کن. خروج، نسخهٔ محلی حساب گوگل را پاک می‌کند؛ اگر تغییرات ارسال‌نشده وجود داشته باشد ابتدا باید سینک شوند. بکاپ JSON در سه بخش یادداشت‌ها، اطلاعات مالی و کامل در تنظیمات قابل دریافت و بازیابی است.

نسخه آنلاین، با تنظیم کلیدهای OAuth و ورود گوگل، دفتر کامل را در D1 همگام می‌کند؛ حالت مهمان محلی است. قیمت‌ها از API واقعی می‌آیند. نسخه دات‌نت را هم می‌توان روی سرور شخصی با SQLite و Google اجرا کرد. تست واقعی OAuth به کلیدها و دامنهٔ خودت نیاز دارد. توضیحات معماری، آزمون‌ها و نگهداری سرور در README.md آمده است.


## امکانات تکمیلی

- Installments: ساخت قسط تکی یا برنامهٔ ماهانه، جمع مانده، جمع سررسیدهای ماه، عقب‌افتاده‌ها و علامت پرداخت.
- Money lent: قرض‌های داده‌شده، ثبت بازپرداخت جزئی و جمع طلب باقی‌مانده.
- Locked assets: دارایی بلوکه، مبلغ کل و تاریخ آزادسازی.
- Market: ۳۹ نماد در دسته رمزارز، فلز، ارز، صندوق و سهام؛ جست‌وجو، واحد و زمان هر نماد و نمودار روزانه، هفتگی و ماهانه.
- Planner: یادداشت با چک‌لیست، کارها، یادآور تکراری و هدف‌ها؛ سنجاق در داشبورد و زنگوله اعلان‌های نخوانده.
- گزارش مالی هم حالت روزانه، هفتگی و ماهانه دارد.

نرخ‌های داخلی از خوراک عمومی TGJU دریافت و از ریال به تومان تبدیل می‌شوند؛ بیت‌کوین به دلار نمایش داده می‌شود. این خوراک قرارداد رسمی API ندارد و ممکن است تغییر کند. نمودار روزانه از مشاهده‌های واقعی پس از اجرا جمع می‌شود؛ نمودار هفتگی/ماهانه از قیمت‌های پایانی موجود استفاده می‌کند. حالت نمونه فقط اطلاعات مالی ساختگی دارد؛ قیمت‌های بازار در همهٔ حالت‌ها از API واقعی دریافت می‌شوند.

برای اعلان وقتی برنامه بسته است، با گوگل وارد شو، اقساط را سینک کن و Enable reminders on this device را بزن. کلیدهای VAPID خودکار روی سرور ساخته و ماندگار می‌شوند. PUSH_SUBJECT را در .env به آدرس تماس خودت تغییر بده. سرور باید روشن و به سرویس Push دسترسی داشته باشد. یادآوری‌ها با ساعت تهران و به‌صورت بهترین تلاش سیستم ارسال می‌شوند؛ محدودیت مرورگر و سیستم‌عامل ممکن است تحویل را به تأخیر بیندازد.

علامت پرداخت قسط، بازپرداخت طلب و آزادسازی دارایی فقط وضعیت همان بخش را تغییر می‌دهند. برای اثر روی موجودی حساب، تراکنش مربوط را هم ثبت کن تا مبالغ دوبار شمرده نشوند.


## زبان و ظاهر

با انتخاب زبان فارسی در تنظیمات، کل رابط راست‌چین و فارسی می‌شود. نام حساب و یادداشت‌های خودت ترجمه یا تغییر داده نمی‌شوند. فونت وزیر برای فارسی و Manrope برای انگلیسی داخل پروژه قرار گرفته‌اند و به سایت فونت خارجی نیاز ندارند.

حالت روشن، تیره و خودکار از تنظیمات قابل انتخاب‌اند. زبان و ظاهر روی همین مرورگر می‌مانند. به‌روزرسانی رابط، اطلاعات قبلی را پاک نمی‌کند. اگر ظاهر قبلی مانده بود، تب‌های قدیمی را ببند و دوباره باز کن.

قیمت طلای ۱۸ عیار، دلار، نقره ۹۹۹ و بیت‌کوین روی داشبورد نمایش داده می‌شود. زمان نرخ و وضعیت تأخیر مشخص است؛ هنگام قطع منبع، آخرین نرخ دریافت‌شده با برچسب تأخیر می‌ماند. نمودار روزانه با مشاهدهٔ واقعی نرخ‌ها ساخته می‌شود و دادهٔ ساختگی جایگزین آن نمی‌شود.
