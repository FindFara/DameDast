# Theme palettes

The five additional app themes use familiar editor palettes as their starting point. Surface shades and muted labels are adapted for app readability; these are not editor syntax themes.

| App theme | Palette source |
| --- | --- |
| Dracula | https://draculatheme.com/spec |
| Nord | https://www.nordtheme.com/docs/colors-and-palettes/ |
| Catppuccin Mocha | https://github.com/catppuccin/catppuccin |
| Tokyo Night | https://github.com/tokyo-night/tokyo-night-vscode-theme |
| Gruvbox | https://github.com/morhetz/gruvbox |

All palettes use the existing CSS variables. No theme package, runtime fetch, font, or image is added. Theme choices apply only after Save. Mobile swatches are 32px within larger labeled touch targets, arranged in five columns.
