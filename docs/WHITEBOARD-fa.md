# بوم دمِ دست — راه‌اندازی، ذخیره و امکانات

از منوی همبرگری، «دست‌نوشته‌ها» را باز کن؛ «دست‌نوشته جدید» بوم تمام‌صفحه را باز می‌کند. بوم‌های قبلی از تصویر پیش‌نمایش همان یادداشت باز می‌شوند. منوی اصلی همبرگری است و منوی طراحی، دکمهٔ سه‌نقطه با نشان قلم دارد. دکمه‌های شناور هنگام باز بودن پنل‌های ویرایش کنار می‌روند تا روی آن‌ها نیفتند. منوی اصلی روی بوم می‌آید؛ انتخاب بخش دیگر، ابتدا ذخیره و سپس خروج از بوم را انجام می‌دهد. نام محصول فقط «دمِ دست / DameDast» است.

## اجرا

پروژه موجود ASP.NET Core 10، Clean Architecture و رابط اصلی JavaScript حفظ شده‌اند. ویرایشگر React/TypeScript/Vite جداگانه در `whiteboard/` ساخته و خروجی آن همراه وب‌اپ ارائه می‌شود. بسته دانلودی، خروجی آماده و فونت‌های محلی را دارد؛ اجرای عادی به Node نیاز ندارد.

```bash
dotnet restore tests/DameDast.Tests/DameDast.Tests.csproj
dotnet run --project src/DameDast.Web --environment Development --urls http://localhost:5000
```

برای تغییر کد ویرایشگر، Node 22.12+ یا 24 و این دستورها لازم‌اند:

```bash
npm ci --prefix whiteboard
npm run build:whiteboard
dotnet run --project src/DameDast.Web --environment Development --urls http://localhost:5000
```

نسخه‌ها دقیق در package.json و package-lock قفل شده‌اند: Excalidraw 0.18.1، React/ReactDOM 19.3.1، Vite 8.3.8، TypeScript 7.0.2 و SignalR JS 10.0.11. وابستگی تست SignalR .NET نسخه 10.0.15 است. وابستگی‌های frontend را با `npm ci` نصب کن.

## داده‌ها کجا می‌مانند؟

| داده | محل |
|---|---|
| عناصر، متن، فریم، اتصال فلش، تصویر و تنظیمات سند | سند نسخه‌دار با schemaVersion=1 و engineVersion=0.18.1 |
| نسخه محلی، تغییرات ارسال‌نشده و شناسه عملیات در حال ارسال | IndexedDB با نام damdast-whiteboards-v1، بخش documents |
| زوم و محل نمایش | بخش ui در همان IndexedDB؛ از سند و درخواست‌های تغییر جداست |
| کتابخانه شخصی اجزا | بخش library در IndexedDB، مجزا برای هر فضای کار |
| عنوان، شناسه بوم و پیش‌نمایش PNG در فهرست یادداشت‌ها | رکورد note دفتر اصلی؛ تصویر کوچک حداکثر حدود ۱۱۰ کیلوبایت |
| نسخه سروری در برنامه .NET | SQLite در data/damedast.db، جدول Whiteboards با JSON کامل سند و revision |
| رسید عملیات تکراری و مجوز لینک | WhiteboardOperations و WhiteboardShares؛ فقط هش توکن لینک ذخیره می‌شود |

ذخیره محلی با تأخیر کوتاه و صف ترتیبی انجام می‌شود. ذخیره قدیمی نمی‌تواند بعد از ذخیره جدید جای آن را بگیرد. هر تب نسخه پیش‌نویس مستقل دارد. خطای ظرفیت/ذخیره پیام و «تلاش دوباره» دارد؛ فایل خراب بی‌خبر جای سند موجود نمی‌نشیند. بکاپ کامل در تنظیمات اکنون سند و بایت تصاویر همه بوم‌های متصل به یادداشت‌ها را هم شامل می‌شود. خروجی مستقل قابل ویرایش نیز در ویرایشگر موجود است. پاک کردن داده‌های مرورگر، نسخه‌های صرفاً محلی را پاک می‌کند.

در نسخه خصوصی میزبانی‌شده، پس از ورود معتبر Google، خود سند و تصاویر در R2 و اشاره‌گر نسخه/مالک/رسید عملیات در D1 ذخیره می‌شوند. محتوای immutable ابتدا نوشته می‌شود؛ سپس اشاره‌گر و رسید با CAS در یک batch اتمیک تغییر می‌کنند. نسخه قبلی پس از موفقیت پاک می‌شود و خواننده هم‌زمان اشاره‌گر تازه را دوباره می‌خواند. قطع ارتباط در لحظه commit ممکن است یک object بدون اشاره‌گر باقی بگذارد؛ پاک‌سازی دوره‌ای این موارد هنوز اضافه نشده است. سندهای R2 آدرس عمومی ندارند.

ورود گوگل به معنی ذخیره فایل در Google Drive نیست: Google هویت کاربر را تأیید می‌کند و داده در دیتابیس/فضای ذخیره سرور خود برنامه نگه داشته می‌شود. هنوز Client ID و Client Secret پروژه گوگل کاربر تنظیم نشده‌اند؛ بدون این دو، ورود و همگام‌سازی واقعی فعال نمی‌شوند. راهنمای تنظیم آن‌ها در GOOGLE-CANVAS-ASSETS-fa.md موجود است.

## ساختار و مسئولیت‌ها

- `Domain/Whiteboards`: مدل سند، محدودیت‌ها و بررسی تعارض نسخه هر عنصر.
- `Application/Interfaces/Whiteboards` و `Services/WhiteboardService`: قرارداد Repository و سرویس کاربردی مستقل از EF.
- `Application/Features/Whiteboards`: Command و Queryهای MediatR؛ endpointها آن‌ها را با CancellationToken فراخوانی می‌کنند.
- `Infrastructure/Persistence/Repositories/WhiteboardRepository`: تراکنش، CAS، idempotency، مجوز مالک/لینک و SQLite.
- `Web/Whiteboards`: Minimal API برای سند/لینک/کتابخانه و SignalR برای حضور/اشاره‌گر/اطلاع از نسخه جدید. کنترلرهای مالی موجود حفظ شده‌اند.
- `whiteboard/src/main.tsx`: رابط و فرمان‌های کاربر؛ موتور رسم همان کامپوننت رسمی است.
- `model.mjs`، `storage.mjs` و `sync.mjs`: فرمت سند، ذخیره محلی و هماهنگ‌کننده همگام‌سازی مستقل و قابل تست.
- `runtime.ts`: اتصال موتور، bridge یادداشت، تصاویر، شبکه و چرخه ذخیره.

زمان سرور از TimeProvider و extension موجود `DameDast.Common.Time.UtcNow()` گرفته می‌شود. عملیات async سرور CancellationToken را به EF، MediatR، HTTP و SignalR منتقل می‌کنند. cleanup قطع اتصال عمداً از توکن لغوشده اتصال استفاده نمی‌کند.

سایت Excalidraw.com سرویس همکاری و ذخیره خودش را دارد؛ این سرویس‌ها همراه npm package منتشر نمی‌شوند. همکاری این پروژه جداگانه ساخته شده و نام/هویت آن «DameDast Canvas» است. نسخه 0.18.1 از APIهای همان نسخه مانند CaptureUpdateAction.NEVER، restore، exportToBlob، exportToSvg و onPointerUp استفاده می‌کند. locale فارسی داخل پکیج هست اما به دلیل پوشش ۸۴٪ از فهرست پیش‌فرض حذف شده؛ از فهرست عمومی languages ثبت شده است. بعضی عنوان‌های پیشرفته ترجمه‌نشده همچنان انگلیسی‌اند.

## همکاری و تعارض

SignalR فقط انتقال نسخه جدید، حضور و اشاره‌گر را انجام می‌دهد. ذخیره REST با نسخه مستقل هر عنصر و نسخه جدا برای عنوان/تنظیمات انجام می‌شود. تغییر دو عنصر مستقل ادغام می‌شود. تغییر هم‌زمان یک عنصر پاسخ 409 و انتخاب «تغییرات من/سرور» دارد؛ ادغام کاراکتری متن و CRDT پیاده نشده است. شناسه عملیات پیش از ارسال ذخیره می‌شود و retry همان شناسه را دارد.

تغییرات سرور با CaptureUpdateAction.NEVER وارد موتور می‌شوند و سابقه Undo محلی را پر نمی‌کنند. Undo کاربر فقط عناصر تغییرکرده را patch می‌کند؛ تغییر مستقل همکار حفظ می‌شود. تعارض روی همان عنصر همچنان نیازمند تصمیم کاربر است. زوم و Hover سابقه سند را تغییر نمی‌دهند.

لینک‌ها ۷ روز اعتبار دارند و در Share قابل لغو هستند. توکن لینک در fragment URL می‌ماند و به API در header ارسال می‌شود. فقط مالک لینک می‌سازد یا لغو می‌کند. API نقش view را روی سرور محدود می‌کند. لغو لینک، مهمان‌ها را از گروه اتاق خارج می‌کند. برای همکاری، همان سرور .NET را با HTTPS، WebSocket و پوشه data ماندگار اجرا کن. نسخه فعلی حضور اتاق را در حافظه یک process دارد؛ برای چند replica به backplane و ذخیره مشترک نیاز است. Long Polling نیز پشتیبانی می‌شود.

حد سند ۸ MB، حداکثر ۳۰۰۰ عنصر و ۵۰ تصویر است؛ هر تصویر حداکثر ۲ MB و از نوع PNG/JPEG/WebP/GIF است. SVG ورودی تصویری و embed خارجی پذیرفته نمی‌شوند. در پیش‌نمایش خصوصی فونت حجیم Xiaolai برای چینی/ژاپنی حذف شده؛ نسخه دانلودی فونت‌های کامل پکیج را دارد. تست روی گوشی واقعی Android و قلم فیزیکی انجام نشده است.

## استفاده و بررسی

برای خروجی، Export → قالب/محدوده/مقیاس → Prepare file → Download. فایل نمونه `samples/sample-flowchart.excalidraw` شامل سه شکل، سه متن فارسی/انگلیسی متصل، دو فلش متصل و یک تصویر است. در منوی فایل، Insert sample flowchart نیز همین ساختار را می‌سازد. Ctrl+O ورود فایل، Ctrl+S پنجره خروجی، Q قفل ابزار، Alt+Q انتخاب آزاد و میانبرهای موتور هنگام تایپ مزاحم IME نمی‌شوند.

```bash
npm test
npm run test:whiteboard
dotnet test tests/DameDast.Tests/DameDast.Tests.csproj
```

نتیجه و محدوده بررسی‌ها در WHITEBOARD-VERIFICATION.md ثبت شده است. راه‌اندازی همکاری واقعی روی میزبان Worker ممکن نیست؛ برای آن خروجی .NET را روی سرور خودت اجرا کن.
